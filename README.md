# HackForge

HackForge is a modern cybersecurity-themed website designed to help beginners learn hardware hacking, embedded security, and ethical hacking concepts. The platform provides structured learning resources, hardware tool guides, project ideas, and a beginner-friendly roadmap for aspiring security enthusiasts.

## Features

- Footer with quick navigation links
- Interactive FAQ Accordion Section
- Interactive Resource Tabs (YouTube, Books, Websites, Labs, Guides)
- Hardware Tools Showcase Cards
- DIY Project Showcase Cards
- Interactive Learning Roadmap Timeline
- Contact Form for community interaction
- Glassmorphism Cybersecurity-themed UI Design
- Featured Learning Paths Section with informational cards

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/hackforge.git
```

2. Open the project folder

```bash
cd hackforge
```

3. Run the website by opening `index.html` in your browser.
