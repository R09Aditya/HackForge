hardware bench

Tools that teach the signals.

A practical catalog of boards and instruments for learning embedded security. The best tool is the one you can safely test, document, and understand.

category 01

RFID/NFC Tools

Useful for studying access cards, reader behavior, and tag protocols in permission-based labs.

F0 Beginner

Flipper Zero

Portable multi-tool for learning RFID, NFC, infrared, GPIO, and basic radio concepts.

P3 Advanced

Proxmark3

Research board for deeper RFID/NFC analysis, tag emulation, and protocol inspection.

PN Beginner

PN532 Breakout

Small NFC module that pairs nicely with Arduino or Raspberry Pi for simple reader labs.

CU Intermediate

ChameleonUltra

Compact RFID emulator for comparing known test tags and studying card behavior.

category 02

Wireless Tools

Start with your own router, dev boards, and test beacons before touching anything public.

E32 Beginner

ESP32

Affordable WiFi and Bluetooth board for packet demos, sensors, and safe network labs.

NRF Intermediate

nRF52840 Dongle

BLE-focused board for advertising, sniffing supported channels, and firmware practice.

AW Intermediate

Alfa WiFi Adapter

External adapter often used in wireless security labs with monitor-mode tooling.

YS Advanced

Yard Stick One

Sub-GHz research tool for controlled radio experiments and protocol learning.

category 03

USB Attack Tools

Use these only on systems you own or have written permission to test.

RD Intermediate

Rubber Ducky

Keystroke-injection platform for awareness demos and defensive testing in a lab VM.

DG Beginner

Digispark ATtiny85

Tiny board that helps explain HID behavior, delays, and why endpoint trust matters.

BB Advanced

Bash Bunny

Multi-role USB device for controlled demos of storage, network, and HID trust issues.

category 04

Embedded Development Boards

Boards are the cheapest way to learn how firmware, pins, and protocols fit together.

UNO Beginner

Arduino

Friendly board for sensors, GPIO, serial basics, and simple embedded C style projects.

PICO Beginner

Raspberry Pi Pico

RP2040 board for MicroPython, C SDK work, PIO experiments, and low-cost labs.

E32 Intermediate

ESP32 DevKit

Good bridge between microcontroller projects and connected-device security concepts.

STM Intermediate

STM32 Nucleo

ARM board family for debugger workflows, datasheets, timers, and peripheral control.

category 05

Electronic Testing Equipment

Measure first. Guessing is how boards get hot, quiet, and expensive.

LA Beginner

Logic Analyzer

Captures digital signals so you can decode UART, SPI, I2C, and timing issues.

OSC Intermediate

Oscilloscope

Shows voltage over time, making clocks, noise, reset lines, and glitches visible.

DMM Beginner

Digital Multimeter

Essential for continuity, voltage checks, resistance, and basic board safety.

UART Beginner

USB-UART Adapter

Connects serial consoles after you confirm voltage level and ground reference.
